# DayBalance 1.1.1

Select dates and times without typing, with a new warm DayBalance app icon.

- Calendar pickers for habits, check-ins, tasks, transactions, recurring entries, report dates, and moving unfinished tasks.
- Month/year selection and a budget month grid.
- Hour, minute, and AM/PM selectors for task times and reminders.
- Cancel preserves the existing value; optional dates and times can be cleared.
- Warm terracotta sunrise/checkmark launcher icon, Android adaptive/themed icons, and a logo in the app header.

Download the attached `DayBalance.apk` and install it over your existing app. Export a JSON backup from Settings first. Uninstalling removes local records. Version 1.1.1 uses Android version code 3, the same package `com.daybalance.app`, and the same signing key as the original release.

Calendar validation: TypeScript, lint, and all 26 tests passed. Browser checks covered selection/cancellation, leap day, month selection, time selection/clearing, date bounds, and phone-width layout. Physical-phone picker interaction and launcher appearance still require device testing.
