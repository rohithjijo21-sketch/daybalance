# DayBalance 1.2.0

Calendar and time selection, a warm new app icon, and in-app Android update notices.

- Tap dates in a calendar with month/year navigation; select budget months from a grid.
- Select task/reminder times using hour, minute and AM/PM controls.
- New terracotta sunrise/checkmark app icon, adaptive/themed launcher artwork, and header logo.
- Automatic Android checks for newer published GitHub APKs on launch/foreground, at most once every six hours.
- “Update available” notice with Update app and Later buttons, plus Check for updates in Settings.
- Tapping Update opens the official GitHub APK download. Android asks you to confirm installation.
- Offline checks do not interrupt your records; app data is never sent to GitHub.

## Install or update

Download the attached `DayBalance.apk` and install over the existing app after exporting a JSON backup in Settings. Uninstalling removes local records. Same package/signing key, version 1.2.0, Android version code 4.

Older installations need this APK installed manually once to gain the update notice feature. After that, the app can discover future published releases; it cannot silently install them.

Physical-phone installer, notification, launcher and picker checks remain pending. See VERIFICATION.md for automated/browser validation.
