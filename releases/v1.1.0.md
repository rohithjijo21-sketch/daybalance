# DayBalance 1.1.0

Choose dates and times by tapping instead of typing.

- Calendar pickers for habits, check-ins, tasks, transactions, recurring entries, report date ranges, and moving unfinished tasks.
- Month/year selection and a month grid for budgets.
- Hour, minute, and AM/PM selectors for task times and reminders.
- Today shortcuts, Cancel without changing a value, and clear actions for optional dates/times.
- Calendars follow the configured first weekday; check-ins block future dates and recurring end dates respect their start date.

## Update on Android

Download the attached `DayBalance.apk` and install it over your existing DayBalance app. Version 1.1.0 uses Android version code 2, the same package (`com.daybalance.app`), and the same signing key as version 1.0.0. Export a JSON backup from Settings before updating. Uninstalling removes local records.

New users can install the APK directly; Expo Go and a running computer are not required.

Validation: strict TypeScript, lint, and all 26 automated tests pass. Browser checks cover calendar selection/cancellation, year/month navigation, leap day, budget month selection, AM/PM selection, clearing time, and phone-width layout. Physical-phone picker interaction still needs testing.
